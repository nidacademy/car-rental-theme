# Changelog

## 1.2.0

- First public release on GitHub.
- Updates itself: new releases show under Dashboard → Updates.
- The "Book now" fallback link on a car page now uses your site's admin email.
- Smaller demo pack: old page backups removed from the demo content, photos cleaned of metadata.
- readme.txt lists the external services the theme uses.

## 1.1.0

- One-click demo import (Appearance → Import demo).
- Car rental system: fleet, prices and discounts, online booking, card deposits with Stripe, customer emails, handover records, dashboard.
- 7 languages, including Arabic with right-to-left layout, and automatic currency switching.
- Header and footer builders, colour themes, car card designs and separate desktop / phone settings in the Customizer.
- Elementor widgets for car listings and brands.
